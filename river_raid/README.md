# River Raid Game

A classic River Raid game implementation using Pygame where the player navigates through a river while avoiding enemies and obstacles.

## Files
- `riverraid.py` - Main game implementation
- `riverraid2.py` - Alternative version of the game
- `river_raid_r1.py` - Revision 1 of the game
- `riverraid.png` - Game sprite/asset
- `highscore.txt` - High score tracking
- `shoot.wav` - Shooting sound effect
- `explosion.wav` - Explosion sound effect
- `refuel.wav` - Refueling sound effect

## How to Run
You can run the games from any directory:

```bash
# From the root directory
python river_raid/riverraid.py

# Or from within the river_raid folder
cd river_raid
python riverraid.py
```

Available versions:
- `python riverraid.py` - Main game version
- `python riverraid2.py` - Alternative version  
- `python river_raid_r1.py` - Enhanced version with more features

## Controls
- **Left Arrow Key**: Move left
- **Right Arrow Key**: Move right  
- **Spacebar**: Fire

## Requirements
- pygame

Install with: `pip install pygame`
