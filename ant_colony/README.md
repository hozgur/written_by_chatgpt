# Ant Colony Simulation

An advanced ant colony simulation that demonstrates swarm intelligence, pathfinding, and emergent behavior patterns.

## Features
- Realistic ant behavior with pheromone trails
- Food collection and nest building
- Swarm intelligence algorithms
- Visual representation of colony dynamics

## Files
- `ants.py` - Main ant colony simulation

## How to Run
```bash
cd ant_colony
python ants.py
```

## Requirements
- pygame
- numpy

Install with: `pip install pygame numpy`

## Simulation Details
The simulation models individual ants with:
- Pheromone-based communication
- Food foraging behavior
- Obstacle avoidance
- Colony coordination
