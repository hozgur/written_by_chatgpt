# Physics & Visual Simulations

Collection of various physics and visual simulations implemented in Python using Pygame and NumPy.

## Projects

### Water Wave Simulations
- `water_1.py` - 2D water wave simulation with mouse interaction
- `water_2.py` - Enhanced water simulation
- `water_3.py` - Advanced water physics
- `chat_for_water.txt` - Development notes

### Particle Systems
- `particles.py` - Optimized particle simulation with NumPy and mouse interaction
- `marble_1.py` - Particle simulation with gravity and collision physics
- `fireworks.py` - Fireworks particle system with physics

## How to Run
```bash
cd simulations
python water_1.py    # Water wave simulation
python particles.py  # Particle system
python marble_1.py   # Marble physics
python fireworks.py  # Fireworks display
```

## Requirements
- pygame
- numpy (for optimized simulations)

Install with: `pip install pygame numpy`
